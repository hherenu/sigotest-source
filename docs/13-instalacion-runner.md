# Instalación del runner

Pendiente del administrador en el repositorio privado de despliegue. Elegir Windows x64 y labels `self-hosted`, `Windows`, `X64`, `sigotest`. El token de registro es efímero y nunca se guarda en Git.

Usar una cuenta de servicio de mínimo privilegio, sin acceso interactivo, con permiso sólo para el directorio de trabajo y el script operativo local. Revisar conectividad saliente, actualización y permisos antes de instalarlo como servicio.
